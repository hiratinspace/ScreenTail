## "Start from where left"

If the owner says "start from where left" (or "resume", "continue where we stopped"), read
`docs/handoff/client-p2-run.md` and continue the run it describes. It lists every open branch and PR,
what each one still needs, and the rules the run follows. Update that file as you go, in the same PR
as the work or in a small docs PR, so the next session can pick up again.
