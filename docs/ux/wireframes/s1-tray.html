Notes

  1. Five icon states: idle, recording (dot), draft ready (count badge), offline (grey, dashed here), service stopped (warning glyph). The tooltip names the tool and elapsed time while recording. Hi-fi uses the Spec §2.4 colours; here the shape carries the difference, so it holds up without colour too.
  2. State line: first row and not clickable. It uses the same words as the HUD, so the two never disagree (INV-4).
  3. Discard session…: during a recording this would break "no modal while recording". See open question Q3 in README.md.
  4. Diagnostics panel: for "is it recording me right now?" and for support calls. Everything is local; nothing here is sent anywhere.
  5. Copy diagnostics: copies state values only. The active window name shows on screen but is left out of the copy (INV-10).

Menu rules

  • Idle, draft ready and offline show Start capture at the top instead of the recording block.
  • Shortcut hints are right-aligned, and every item is reachable with the arrow keys.
