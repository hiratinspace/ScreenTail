Notes

  1. Pill: 44 px tall, fully rounded, draggable; its position is remembered. Always on top, never takes focus, and hidden from ScreenTail's own screenshots. That hiding already passes on Windows in ST-001 (AC3). Controls are 32 × 32 (Spec §7). Screen-reader text: "Recording, 12 minutes 41 seconds, 3 items redacted".
  2. Click to expand: shows the last 3 timeline events and Mark moment (Ctrl+Alt+M). Double-click opens Review for the current session, read-only until you stop.
  3. Right-click: hides the HUD for this session only. The tray still shows recording, so capture is never silent (INV-4).
  4. Wording: Spec S2 says "Paused: elevated window", but ST-021 says "Elevated window — screen not captured". Open question Q5.

State cues in low-fi

  • Solid border = recording. Dashed = paused or suppressed (amber in hi-fi). Hatched fill = out of scope (violet). Grey text = degraded (mic missing, offline).
  • Every state is spelled out in words, so none of them depends on colour.

Screen sharing

Open question Q1. The same capture exclusion that keeps the HUD out of ScreenTail's screenshots also keeps it out of Teams and Zoom screen shares, so the person watching never sees it and the technician always does. Recommendation: always visible.
