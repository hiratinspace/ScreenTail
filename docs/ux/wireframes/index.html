ScreenTail v1 wireframes

Greyscale on purpose: these settle layout, content, states and flow. Colour, type and tokens come in ST-015 and ST-016. Every screen follows Build Plan/01-UX-Design-Spec.md §5; each note links back to the spec section it implements.

How to use them: the state buttons in the dark bar switch each screen between its states. Blue numbers are callouts that match the notes; press C to hide them. S3 Review works with the keyboard.
